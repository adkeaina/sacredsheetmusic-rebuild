# Feature register

The approved design is authoritative. The public Rails repository was inspected at aee05fb18aef1b603de2006beeb11a75704481f4, including inherited Substruct routes. The original site could not be rendered in the research environment, so visual or production-data parity is not asserted. This is an independent implementation with fictional metadata and owned demonstration files.

Administrator forms expose clear field names; times currently use Unix milliseconds. Taxonomy and composer changes create resumable index/reconciliation jobs; Diagnostics can resume them. The original database, music permissions and full file inventory are still required for a real migration. Administrative account linking/removal should be reviewed with the maintainer's real identity model before importing users; preview registration never claims existing composer names automatically.
