# Media provenance

All files in `public/fixtures` are original demonstration exercises generated by `scripts/fixtures.ts` for this application. The PDF/SVG are a simple repeated notation exercise; WAV/MP3/MIDI are a short synthesized example. They are explicitly sample content, not scores or recordings for the fictional catalog titles, and contain no original-site repertoire. Regenerate with `npx tsx scripts/fixtures.ts` (requires FFmpeg for MP3 encoding).

The interface uses locally bundled Great Vibes and Source Sans 3 from their fontsource packages; retain their bundled license files. PDF.js, pdf-lib, ffmpeg.wasm and its codec core retain their upstream package licenses. Existing website artwork, PDFs, recordings, biographies, advertisements, analytics and sponsors are not redistributed.
